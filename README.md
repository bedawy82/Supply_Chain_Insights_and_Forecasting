# 📊 Supply Chain Insights and Forecasting Dashboard

An interactive end-to-end data analytics project that analyzes and forecasts key supply chain metrics such as sales, profits, and lead times using Python, Prophet, and Streamlit.

---

## 🚀 Project Overview
This project performs:
1. **Data Cleaning & Preprocessing** using Pandas and NumPy  
2. **Exploratory Data Analysis (EDA)** and KPI generation  
3. **Interactive Dashboard** built with Streamlit and Plotly  
4. **Forecasting and Demand Prediction** using Prophet  
5. **Automated Report Exports** in Excel, HTML, and PowerPoint formats  

---

## 🧠 Key Insights
- Analyze revenue, profit, and product category trends  
- Explore relationships between regions, suppliers, and performance metrics  
- Forecast future demand, sales, and supply chain timelines  

---

## 🛠️ Tools & Libraries
- **Python** (Pandas, NumPy, Matplotlib, Plotly)
- **Prophet** (for forecasting)
- **Streamlit** (for dashboard UI)
- **OpenPyXL** and **python-pptx** (for report generation)
